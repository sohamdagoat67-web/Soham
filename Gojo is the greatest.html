01 - Concept

Why a New Language?

Speed: Writing "Sodium Chloride" is long, "NaCl" is instant Universal: Same symbol understood in India, Japan, USA Origin: Berzelius (1813) gave modern 1-2 letter system
ICSE Key: Language = Symbols + Formulae + Equations

02 - Symbols

How to Write Correctly

Rule A: First letter CAPITAL only - H for Hydrogen Rule B: Two-letter element symbols use 1st Capital + 2nd Small - Co is Cobalt; CO is Carbon Monoxide Rule C: Latin roots - Ferrum=Fe, Natrium=Na, Kalium=K
Trick: Element symbols are case-sensitive. NaCl = Na + Cl, while CO is the formula for carbon monoxide.

04 - Valency

How Many Hands?

1: H, Na, K, Cl - can hold 1 hand 2: O, Mg, Ca - holds 2 hands 3: Al, N - holds 3 4: C, Si - holds 4 Example: Mg²⁺ + Cl⁻ → MgCl₂ Example: Al³⁺ + O²⁻ → Al₂O₃

05 - Radicals

Group Acting as One

Basic: NH4+ Ammonium Acidic (1): OH- Hydroxyl, NO3- Nitrate Acidic (2): SO4 2- Sulphate, CO3 2- Carbonate Acidic (3): PO4 3- Phosphate Example: Ca²⁺ + CO₃²⁻ → CaCO₃ Example: Mg²⁺ + OH⁻ → Mg(OH)₂
Radical = a group of atoms that acts as a single unit in a compound.

07 - Chemical Equation

Reaction in Short

Reactants (LHS) -> Products (RHS). Example: C + O2 -> CO2 Must be BALANCED - same number of atoms both sides - Law of Conservation Example: 2H2 + O2 -> 2H2O (4H, 2O both sides)
